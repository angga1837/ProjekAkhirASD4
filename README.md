### 📖 Deskripsi Proyek
**SENORA (SEMINAR AND WORKSHOP REGISTRATION APPLICATION)** merupakan aplikasi yang dirancang untuk membantu proses pengelolaan seminar dan workshop di lingkungan akademik dan non-akademik.  
Sistem ini memungkinkan pengguna (User) untuk melakukan registrasi dan memilih seminar, serta Admin untuk mengelola data peserta dan seminar.

---

### ⚙️ Fitur Utama
- 🔐 Registrasi dan log in User  
- 👤 Log in Admin  
- 📋 Pendaftaran seminar/workshop  
- 🗂️ Pengelolaan data peserta  
- 🧾 Verifikasi peserta  
- 📊 Riwayat pendaftaran  

---

### 🛠️ Teknologi yang Digunakan
- Bahasa Pemrograman: **C++**  
- Library: **Standard Library (STL)**
